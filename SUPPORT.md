# Soporte

Este documento explica como pedir ayuda o reportar problemas dentro de los repositorios de Outlier.

## Para errores de software

Crea un issue usando la plantilla **Bug report** e incluye:

- que esperabas que ocurriera;
- que ocurrio realmente;
- pasos para reproducir;
- ambiente afectado;
- capturas, logs o evidencia;
- impacto operacional.

## Para nuevas funcionalidades

Crea un issue usando la plantilla **Feature request** e incluye:

- problema que se busca resolver;
- usuario o proceso afectado;
- resultado esperado;
- prioridad;
- restricciones conocidas;
- criterios de aceptacion.

## Para tareas tecnicas

Crea un issue usando la plantilla **Task** cuando se trate de:

- documentacion;
- configuracion;
- mejoras internas;
- automatizaciones;
- soporte operativo;
- limpieza o mantenimiento.

## Para seguridad

No abras issues publicos sobre vulnerabilidades, secretos o exposicion de datos. Sigue la politica definida en [SECURITY.md](SECURITY.md).

## Para soporte urgente

Usa los canales internos definidos por el equipo o producto. El issue debe quedar registrado despues para mantener trazabilidad.
