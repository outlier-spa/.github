## Uso recomendado

- Usar estas guias para crear nuevos repositorios.
- Aplicarlas gradualmente a repositorios existentes.
- No renombrar repositorios productivos sin evaluar impacto en pipelines, paquetes, documentacion y dependencias.
- Priorizar primero topics, descripcion, README y estado de ciclo de vida.
